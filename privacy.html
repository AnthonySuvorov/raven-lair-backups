Privacy Policy

Raven Lair Backups

Last updated: November 20, 2026

1. Purpose

Raven Lair Backups is a private utility used to create and store backups for the Raven Lair Discord bot.

2. Information We Access

The application accesses Google Drive through the Google Drive API using the account explicitly authorized by the owner. It creates and manages backup files and folders created by this application.

3. How Information Is Used

Google Drive access is used solely to upload, maintain and restore backup files for the Discord bot. The application does not sell personal information or use Google Drive data for advertising.

4. Data Sharing

The application does not share Google Drive data with third parties. Backup access is restricted to the authorized account owner and the systems required to operate the backup service.

5. Data Storage and Security

Backup files are stored in the Google Drive account selected by the owner. Reasonable measures are used to protect credentials and backup data from unauthorized access.

6. Data Retention and Deletion

Backup files are retained according to the owner's backup retention settings. The owner can delete backup files from Google Drive at any time.
